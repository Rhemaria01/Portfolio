# Portfolio

Personal portfolio site for Reenav Hemaria — Next.js, React, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

Deployed via [Netlify](https://www.netlify.com/) from [Rhemaria01/Portfolio](https://github.com/Rhemaria01/Portfolio).
